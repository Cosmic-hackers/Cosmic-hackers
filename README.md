## 🛠️ **Setup Guide**

### 1. **Required Assets**
Create `/assets` folder in your repo and add these SVGs:

#### `tech-sphere.svg`
```xml
<svg width="300" height="300" xmlns="http://www.w3.org/2000/svg">
  <!-- 3D Tech Sphere Code -->
  <style>
    .tech-sphere { animation: rotate 20s infinite linear; }
    @keyframes rotate { 100% { transform: rotateY(360deg); } }
  </style>
  <g class="tech-sphere">
    <!-- Sphere layers with tech icons -->
  </g>
</svg>
```

#### `cyber-mandala.svg`
```xml
<svg width="250" height="250" viewBox="0 0 100 100">
  <!-- Intricate cyber-themed mandala -->
  <path d="..." fill="#58A6FF" opacity="0.7">
    <animate attributeName="opacity" values="0.7;1;0.7" dur="5s" repeatCount="indefinite"/>
  </path>
</svg>
```

### 2. **Auto-Updating Features**

#### WakaTime Stats
1. Sign up at [WakaTime](https://wakatime.com)
2. Add this to `.github/workflows/wakatime.yml`:
```yaml
name: WakaTime Stats
on:
  schedule:
    - cron: '0 0 * * *'
jobs:
  update-readme:
    runs-on: ubuntu-latest
    steps:
      - uses: anmol098/waka-readme-stats@master
        with:
          WAKATIME_API_KEY: ${{ secrets.WAKATIME_API_KEY }}
          GH_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

#### Dynamic Jokes
No setup needed - uses [readme-jokes.vercel.app](https://github.com/ABSphreak/readme-jokes)

### 3. **Animations**
Add this CSS via SVG (works in GitHub README):
```xml
<svg>
  <style>
    .twinkle { animation: pulse 2s infinite alternate; }
    @keyframes pulse { to { opacity: 0.3; } }
  </style>
  <circle class="twinkle" ... />
</svg>
```
